# 🤟 Sign Language to Text & Speech

Real-time sign language recognition system using
CNN + OpenCV + Computer Vision.

## 🚀 Features
- Real-time webcam recognition
- Sign → Text conversion
- Text → Speech conversion
- CNN-based gesture classification
- Hand detection and preprocessing

## 🛠️ Technologies
- Python
- TensorFlow / Keras
- OpenCV
- MediaPipe / CVZone
- NumPy
- Tkinter
- pyttsx3
